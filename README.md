# Focus-group-transcripts-and-SUS-questionnaire-data
The file `sus.csv` contains the System Usability Scale (SUS) data.

In this dataset, the variable `ehmi_id` indicates the eHMI design condition:

- `E1` represents Brake-eHMI
- `E4` represents Video-eHMI

Please refer to this mapping when interpreting or analyzing the SUS scores.
